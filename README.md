# 📊 Obsidian WorkOS Dashboard

**Interactive React 18 + Tailwind Kanban Dashboard, Workstream Swimlanes, Omnibar & Agent Hub for Obsidian WorkOS.**

---

## ⚡ Features
- **Live Kanban Board**: Drag & Drop tasks across status columns (`Inbox`, `Todo`, `In Progress`, `Done`).
- **Workstream Swimlanes**: Switch between standard columns and horizontal project swimlanes.
- **Omnibar Quick-Capture**: Fast-entry modal with intelligent parsing of tags (`#tag`), priorities (`!high`), and workstreams (`@stream`).
- **Agent Hub & AI Control Center**:
  - Direct 1-Click execution of AI Triage (`window.WorkOSAgentSuite.triageInbox()`).
  - Human-in-the-Loop Review Queue (`[ ✅ Freigeben & Done ]`).
  - Live Connection Status to `WorkOS Agent Suite`.
- **Metrics Widget**: Visual progress bars, completion rates, and workload statistics.
